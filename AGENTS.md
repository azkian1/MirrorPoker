# Mirror Poker

This repository is the standalone browser edition. Read README.md and Project.md.

- Keep project text in English and preserve the two-world poker rules.
- Use npm dependencies and local assets. The game must run without Remix, an account, API keys, or a remote game server.
- Keep engine rules, bot policy, session timing, scene anchors, and card privacy covered by regression tests.
- Run `npm run check` after code changes and `npm run test:browser` after integration or interface changes.
- Keep third-party notices and asset provenance. Do not commit dependencies, generated bundles, captures, credentials, or platform account data.
- Distinguish automated browser checks from physical-device testing.
